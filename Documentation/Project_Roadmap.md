# CRM Analytics Project Roadmap

## Phase 1 — Python / Data Cleaning

- Load and inspect data
- `info()`, `describe()`, `shape`
- Missing values
- Duplicates
- Data types
- Date validation
- Text cleaning
- Standardizing categories
- Outlier detection
- Invalid values
- Logical validation
- Cleaning and transformation
- Export cleaned CRM data

## Phase 2 — Python / EDA

- Customer analysis
- Lead funnel analysis
- Conversion analysis
- Revenue analysis
- Sales representative performance
- Marketing source performance
- Customer satisfaction
- Response time
- Segment and industry analysis
- Correlation analysis
- Business insights

## Phase 3 — Power Query

- Import raw/cleaned data
- Transformations
- Data types
- Cleaning
- Parameters where needed

## Phase 4 — Data Modeling

Build a dimensional model rather than keeping all analysis in one flat table.

Target structure:

- Fact CRM
- Dim Customer
- Dim Date
- Dim Product
- Dim Sales Rep
- Dim Campaign
- Funnel Stages
- Score Band

## Phase 5 — DAX

Core measures include:

- Total Revenue
- Total Customers
- Total Leads
- Won Leads
- Lost Leads
- Conversion Rate
- Average Revenue
- Average Lead Score
- Average Response Time
- Customer Satisfaction
- Revenue Growth
- Supporting KPI and custom-visual measures

## Phase 6 — Professional Power BI Dashboard

Build a portfolio-level dashboard focused on business questions, KPI visibility, funnel performance, revenue, customer experience, response time, lead quality, and actionable insights.
