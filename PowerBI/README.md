# Power BI Dashboard

## CRM 360 — Sales & Customer Analytics

`CRM_360_Sales_Customer_Analytics_Dashboard.pbix` is the main interactive BI deliverable for this project.

### Dashboard Scope

- Executive CRM KPIs
- Lead funnel and conversion performance
- Revenue and pipeline analysis
- Customer and segment analysis
- Sales representative performance
- Campaign and marketing-source analysis
- Lead-score performance
- Customer satisfaction
- Response-time monitoring

### Model

The PBIX uses a dimensional model with CRM analytical data and supporting dimensions for customer, date, product, sales representative, campaign, funnel stages, and score bands.

### Measures

DAX documentation is available in the repository `DAX/` folder, including core KPI measures and HTML-based custom visual measures.

### Dataset

The dashboard is based on the cleaned CRM analytical dataset. The public repository contains a sanitized version without direct customer identity/contact fields.
