# Python Analysis

This folder contains the public GitHub versions of the Python/Jupyter workflow used to prepare and analyze the CRM dataset.

## Notebooks

1. **01_CRM_Phase1_Cleaning.ipynb** — data inspection, profiling, cleaning, validation, standardization, and derived fields.
2. **02_CRM_Phase2_EDA.ipynb** — customer, lead funnel, conversion, revenue, sales representative, marketing source, satisfaction, response-time, segment, and industry analysis.
3. **03_CRM_Dashboard.ipynb** — analytical outputs and visual exploration supporting the Power BI dashboard.

## Public Version

Notebook outputs were cleared before publication to avoid exposing raw CRM records. The analytical code and workflow structure are preserved.

The published dataset is `Data/CRM_Cleaned_Public.csv`. Raw CRM data is intentionally not included in the repository.
