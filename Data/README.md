# Data

This folder contains the public-safe CRM dataset used for the portfolio project.

## Published Dataset

`CRM_Cleaned_Public.csv`

- 5,000 records
- Cleaned and transformed CRM data
- Direct identity/contact fields removed for public sharing
- Suitable for analysis and dashboard reproduction

## Removed Direct Identifiers

The public version excludes fields such as:

- Full name
- First name
- Last name
- Email
- Phone

The original raw CRM dataset is not published in this repository.
